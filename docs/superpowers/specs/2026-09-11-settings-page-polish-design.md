# 设置页精装化设计规格

## 目标

将控制中心的“设置”页面从原生 WPF 控件堆叠，升级为与 `docs/prototypes/usagelens-tray-dashboard.html` 一致的深色精装卡片界面；不改变任何设置项、命令、绑定或数据读取行为。

## 范围与约束

- 保留外观、悬浮行为、数据刷新、托盘与启动、隐私与诊断五个区域及其全部既有控件。
- 不展示账号邮箱、订阅类型或其他身份信息；顶部状态区只显示安全的本机 Codex 连接说明和动态状态。
- 继续使用现有 `SettingsViewModel` 属性和命令，不新增持久化字段。
- 控件保持键盘可访问，既有 `AutomationProperties.Name` 不移除。
- 只修改设置页视觉层，不影响悬浮窗、托盘、刷新和诊断逻辑。

## 视觉系统

- 背景与卡片：深海军蓝背景，卡片使用 `#101F2F` 到 `#14283A` 的层次，细边框 `#203B52`，圆角 16px。
- 文字：标题 `#F0F6FC`，正文 `#C8D6E5`，辅助说明 `#7F94AA`。
- 强调色：启用状态、滑块和主操作使用薄荷绿 `#69E0B4`；警告/重置操作使用暖色边框，不使用高饱和大面积填充。
- 样式选择：四个等宽胶囊按钮，选中项显示绿色描边与淡绿色底色。
- 开关：40×22px 圆角轨道，开启状态为绿色，关闭状态为低对比蓝灰色。
- 下拉框和按钮：统一 32px 高度、8px 圆角、深色填充；避免系统白底控件。

## 布局

- 页面顶部为一行安全连接状态卡，显示“Codex 连接状态”、动态状态和“不会读取或保存凭据”的说明。
- 中段为两列卡片：外观 / 悬浮行为、数据刷新 / 托盘与启动。
- 隐私与诊断独占一行，状态使用四个紧凑信息块显示。
- 每个设置项都使用“标签 + 一句说明 + 右侧操作控件”的行式结构，并以低对比细分隔线分组。

## 验收标准

1. 页面中不再出现系统白底按钮、默认复选框或默认单选框。
2. 现有所有设置仍可设置、即时生效并保留到原有设置存储。
3. 样式选择、透明度、折叠、刷新、托盘、诊断与重置命令均保持原有绑定。
4. 诊断状态、加载反馈和无数据状态仍可见；不显示任何真实账号身份。
5. XAML 可通过 Release 构建，现有设置与呈现测试通过。
