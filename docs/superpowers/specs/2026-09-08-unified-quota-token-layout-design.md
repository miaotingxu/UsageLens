# 额度与 Token 同屏布局设计

## 目标

取消额度页与 Token 页的小圆点切换。悬浮窗在展开状态同时呈现两个额度窗口、倒计时、进度条、当日/近7天/近30天 Token 总量与估算价格。

## 决定

- 使用上下双区布局，不使用左右双栏或悬停二次展开。
- 窗口宽度保持 300px；展开高度从 140px 调整为 205px，卡片高度调整为 195px。
- 顶部额度区保留当前两行、重置时间、颜色与 2px 进度条。
- 中部用细分隔线分开 Token 区；Token 三行继续显示总量和价格。
- 移除页码点、页面切换状态及对应点击处理器。
- 1秒自动折叠、80×8 把手、置顶、透明度、刷新和右键菜单均保持不变。

## 验收标准

- 展开时没有任何页面切换控件，两个数据区域均可见。
- Token 与额度任一读取失败时，另一部分仍按原逻辑显示。
- 折叠和展开不改变刷新状态或清空显示值。
- Release 单文件程序能够启动并显示同屏布局。
